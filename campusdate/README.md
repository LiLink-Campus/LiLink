# CampusDate 本地 UI 预览

启动：

```sh
python3 /Users/yoryon/LiLink/LiLink/campusdate/server.py
```

打开 http://127.0.0.1:4173/sjtu/dashboard 。底部工具条可切换仪表盘、问卷、配对揭晓、个人设置、通知。配对页点击信封查看虚拟匹配结果。

## 来源与范围

2026-09-10 下载自 https://trycampusdate.com/sjtu 实际公开引用的 Vue 编译资源、CSS、字体和图片，以及公开的学校配置接口。原站页面资源保持原样；index.html 增加本地模拟脚本及网络限制。

preview.js 提供虚拟人物、匹配分数、通知与历史记录。没有访问受保护数据，没有真实账号或有效令牌；页面不连接原站后端。只支持本机运行。

这是一份界面预览：表单、弹窗及动画来自公开前端，提交响应仅为本地模拟，不代表原站业务成功，模拟修改一般不持久化。活动、优惠券、人格等未配置的数据可能显示空状态。不要把虚拟配对内容当成真实产品结果。

server.py 仅监听 127.0.0.1，提供 SPA 路由。Ctrl+C 停止。无需 npm 安装。download.py 为一次性来源下载脚本，重新执行会覆盖入口 HTML，不要在现有预览上直接运行；恢复资源请使用独立目录。

未 commit 或 push。第三方资源用于本地设计研究。

# LiLink 项目文档

本目录管理现行行为、操作说明、设计决策、实施计划和有日期的开发证据。每项事实只有一个维护位置：代码和配置定义可执行行为，参考文档解释行为契约，其他页面通过链接引用。目录入口负责导航，历史资料保留当时的上下文。

## 按任务阅读

| 任务 | 阅读入口 |
| --- | --- |

| 理解账户、匹配、VIP、优惠券和拓扑 | [现行参考](reference/README.md) |

| 追溯开发进程和发布观察 | [实施记录](records/README.md) |

## 文档效力

现行参考说明当前源码的契约，不能单独证明某环境正在运行同一版本。计划是提案；决策保留提出、采纳、撤回与实现的时间边界；验收和发布记录只证明注明的环境与观察时点。历史页面中的 Agent 指令与“当前”“尚未部署”均不构成今天的执行指令。

未脱敏交接原件统一位于 Git 忽略的 `docs/private/`，公开索引不链接私有文件。凭据继续使用受控存储，文档及验收工件不记录凭据或真实用户数据。

## 新文档与命名

按 [Seiso 文档维护](guides/documentation.md) 选择文档职责。新需求使用 [模板入口](templates/README.md)；现行说明使用稳定主题名，决策、计划、记录和归档使用事件日期与主题命名。日期来源及未确认事项显式注明，不依据 Git 收录日期推断业务事件日期。

每个文档分类有 `README.md` 作为父页面，列出职责、效力、模板与命名规则。子文档使用相对链接指向父页面，引用事实时指向其维护位置。

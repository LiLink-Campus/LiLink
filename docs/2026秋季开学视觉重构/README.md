## 启动

在仓库根目录执行：

```sh
node 'docs/2026秋季开学视觉重构/start.mjs'
```

浏览器打开 <http://localhost:3101/>。后端使用本地 4000 端口，数据来自本地数据库；原站 3000 端口服务保持关闭。

使用 webpack 启动，以避开当前 Turbopack 在中文目录下出现的编译错误。启动器不会把原站再次覆盖到副本，因此后续在 `web/` 中的修改可以持续保留。

## 视觉预览模式（2026-09-09）

通过上述启动器打开 3101 副本时，自动启用开发专用视觉预览。登录、学校邮箱注册、普通邮箱注册和找回密码均可留空直接点击主按钮，逐步查看后续界面。不会发送验证码、创建账号或修改真实用户资料。

页面右下角「视觉预览」提供用户页面跳转，以及等待揭晓、匹配成功、已交换联系方式、本轮未匹配四种状态。匹配资料自动提供完整虚拟答案；见面安排预填两个时间、两个地点，可连续查看三步界面。个人中心、名片、邀请、优惠券和见面详情可直接访问。此处为用户端视觉预览，不包含运营管理后台或商家后台。

数据来自 `web/src/lib/visual-preview/` 与现有 Storybook 虚拟数据。问卷题目和可注册学校来自当前本地公开接口快照（2026-09-09），不修改后台白名单。普通操作仅模拟响应，刷新会恢复示例资料；匹配展示状态在当前浏览器保留到再次选择。适合查看界面，不代表业务已执行。

预览仅在本副本的 Next.js 开发模式启用，本机地址有效，生产构建禁用。原站 `apps/web` 与真实后端认证逻辑均未修改。

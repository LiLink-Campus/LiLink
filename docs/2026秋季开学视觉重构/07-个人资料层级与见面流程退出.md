# 个人资料层级与见面流程退出

2026-09-10，已在 3101 设计副本实施，供继续视觉评审。

## 问题与决策

原「关于你」包含基本信息，昵称、自我介绍、联系方式却放在「我的 → 编辑引荐名片」，同一用户资料被分成两个编辑入口。首页将本轮报名、历史匹配、见面和补充微信混成带高低优先级的待办，难以判断当前状态。

统一导航为「我的资料」，按用户填写目的分三组：

| 分组 | 信息 | 保存方式 |
| --- | --- | --- |
| 关于你 / 自我介绍 | 昵称、一句话介绍 | 接入现有问卷自动保存 |
| 关于你 / 联系方式 | 首选邮箱、微信、QQ 或手机号 | 展开编辑后独立保存，不覆盖问卷 |
| 关于你 / 基本信息 | 出生日期、性别、国籍、语言、外貌自评、身高、体重 | 现有问卷自动保存 |
| 希望遇见谁 | 对方条件及偏好 | 现有问卷自动保存 |
| 价值观 | 现有 24 题 | 现有问卷自动保存 |

「我的」只保留资料入口、邀请、优惠券和账号服务，不再维护第二套名片编辑入口。旧 `/dashboard/me/card` 重定向至 `/dashboard/profile`；缺失自我介绍的跳转指向资料页对应字段。草稿/完整状态、自动保存与失败重试保留；输入与保存异常不会显示为成功。

界面去除重复的说明卡与问题卡背景，保留一个分组导航、分节标题和清楚的字段分隔。联系方式默认收起，减少首屏堆叠。昵称和介绍用于向匹配对象展示；联系方式文案说明交换后用于联系。

## 首页

1. 下次揭晓时间。
2. 本轮参与：是否参加、当前意向、修改或取消入口；缺失必填资料时显示补全入口。
3. 已揭晓的匹配：匹配结果及交换联系方式状态。
4. 资料与服务：可选的联系方式编辑和优惠券。

移除任务高/中/低标签。已交换联系方式不再作为待确认任务，使用默认邮箱也不构成必须补充微信的任务。意向显示中文。

## 退出见面流程

用户明确决定不再做站内见面安排及衍生页面。预览的产品流程结束于匹配、交换联系方式，后续交流由双方自行决定。

- 首页停止产生见面任务。
- 匹配页移除发起见面邀请、下一步安排见面、见面状态条。
- 未交换时保留「交换联系方式」作为主按钮；已交换时展示联系方式。
- 预览工具移除安排见面与见面详情。
- `/dashboard/meetup/start` 和 `/dashboard/meetup/[sessionId]` 回到匹配页。

本轮仅改设计副本。原站前后端、数据库和线上服务未进行功能下线；旧组件源码尚未作仓库级删除。后续正式实现时按上述边界清理 API、定时任务、通知、数据与测试，不将这次预览退出视为生产下线完成。

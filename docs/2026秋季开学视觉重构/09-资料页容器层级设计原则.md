# 资料页容器层级设计原则与方案

## 本轮问题

用户认为我的资料存在过多框框套框框。当前界面叠加模块按钮、独立题卡、输入边框、选项胶囊与保存提示背景，多个层级同时争夺注意力。本轮为资料调研及设计图探索，不修改运行页面。

## 查阅来源

- NN/g Visual Hierarchy: https://www.nngroup.com/articles/visual-hierarchy-ux-definition/
  分组可通过邻近、留白或容器边界建立，不要求每一层都加框。
- NN/g Common Region: https://www.nngroup.com/articles/common-region/
  明确边界是强分组信号，可能压过邻近关系。
- NN/g Similarity Principle: https://www.nngroup.com/articles/gestalt-similarity/
  一致的颜色和样式有助于识别可点击元素。
- GOV.UK Question Pages: https://design-system.service.gov.uk/patterns/question-pages/
  建议从一页处理一件事开始，再根据用户研究决定是否合并。

## 对 LiLink 的具体判断

以下是本项目设计建议，不是来源规定的硬性条款：

1. 同一分组优先只保留一层视觉边界：保留输入框时去掉外层题卡；保留题卡时内部采用清楚的标签、行内编辑与焦点样式。
2. 标题、间距和对齐先承担分组职责，避免重复使用背景、边框、阴影、分割线。
3. 减少容器不等于隐藏操作：可编辑字段仍需要清楚标签、编辑按钮或焦点状态。必要的输入边界不能为美观随意移除。
4. 单选可采用原生圆形控件，不必将每个选项再包装成胶囊。
5. 自动保存提示清楚但轻量；错误与未保存状态仍需突出，不能只藏在图标或悬浮提示里。
6. 单题模式可降低同屏复杂度，但增加往返操作，应保留总览和回看能力，不能推断适合所有用户。

## 本轮设计图

`设计参考/我的资料-容器层级三方案.png`

- A 仅保留控件边界：去掉外层卡片，直接编辑，操作路径短。
- B 单层纸面：保留一层整体容器，内部采用行内编辑，更柔和，需验证编辑可发现性。
- C 单题聚焦：题目和选项直接呈现，一次聚焦一题，适合长价值观问卷的备选模式。

图为生图模型输出的结构探索稿，不是完整交互规格。A 图遗漏保存提示、部分图仅展示当前邮箱输入，不覆盖已接受的全部行为；正式实现须保留邮箱/微信/QQ/电话直接填写和首选展示选择、真实保存状态、失败重试、已记录的字段精简决策。单题模式也未获得实施确认。

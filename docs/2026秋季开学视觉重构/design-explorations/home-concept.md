# 首页：活动入口与参与引导设计稿

日期：2026-09-11。独立交互提案，尚未替换 `/dashboard`。

预览：http://127.0.0.1:3101/home-concept.html

源文件：`../web/public/home-concept.html`。复用现有校园插画和本地字体，无新增依赖。

## 设计判断

现有首页的倒计时、参与状态、联系方式分散在同等权重的卡片中。提案将本轮状态、下一步操作和揭晓日期合并；将联系方式降为辅助信息。

桌面顶部采用左主任务、右活动入口。手机将活动收为短横幅，放在主任务前。当前只呈现一个活动，不自动轮播；以后按当前活动更换内容。

三步引导常驻，并根据用户状态标记当前位置。详细说明由用户主动展开，不强制弹出。核心文案是“填写资料后，还需要确认参加”和“本轮无需再操作”。

## 状态

| 状态 | 主操作 | 说明 |
| --- | --- | --- |
| 首次加入 | 去完成匹配资料 | 明确尚未报名 |
| 待参加 | 选择意向并参加 | 意向选择后演示已参加 |
| 已参加 | 更换本周意向 | 取消参与为次级操作，需二次确认 |
| 报名已锁定 | 查看参与说明 | 不能更改或取消 |
| 匹配已揭晓 | 查看本轮匹配 | 到已有匹配页继续 |
| 本轮未匹配 | 看看我的资料 | 提醒下轮开放后确认参加 |

## 1v1 入口

参考用户提供的「设计一对一交付」对话：页面登记意向，工作人员人工联系，标准套餐另行确认，不做支付系统。对话中的价格与推荐次数并非已确认产品配置，本稿不使用。

可点击链路：活动入口 → 服务介绍 → 意向登记 → 演示完成。登记表仅用于设计评审，不发送、保存或接入真实数据。当前为弹窗演示；正式活动可拥有可独立分享的详情页。

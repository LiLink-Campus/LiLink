## 测试稳定性处理

- 用可见业务状态和 DOM 就绪判断页面可操作，不等待无关外部图片完成下载。
- 首次访问先关闭实际公告，避免未完成客户端初始化时填表被覆盖。
- 退出登录后等待应用跳转结束，再检查受保护页面。
- 定位限定在当前可访问区域，排除 Next.js 保留的隐藏页面副本。
- 每条用例使用独立合成 IP，另有同一 IP 限流用例保证安全规则未被关闭。
- 多选测试数据严格满足选择数量；报名拒绝用例使用正确 DTO，并检查确为资料门槛错误。
- 匹配展示数据包含已揭晓和正式介绍状态，避免把尚未正式介绍的记录当作成功匹配。

## 覆盖边界

完整问卷的准备通过真实 API；浏览器验证资料修改、保存、草稿与刷新回读，尚未逐题操作整张新用户问卷。匹配结果测试验证展示，不替代已有 API 算法和周期执行测试。PWA 离线/升级、真实支付和真实邮件到达率不在本套件内。

GitHub Actions 需工作区改动提交推送后才会触发。Linux ARM64 本机容器不替代 GitHub runner 的实际运行结果。

# 人工匹配手机号登记

## 行为

活动页两个「免费登记意向」按钮打开手机号表单。国际区号默认 +86，填写手机号并同意运营联系后提交；成功显示登记成功，失败保留内容以便重试。手机号标准化后去重，不在公开接口返回手机号或登记记录。

管理后台新增 `/admin/match-leads`「人工匹配登记」入口，查看手机号、登记时间与待联系/已联系状态，支持标记和恢复待联系。接口由 AdminGuard 保护。未接入微信咨询、付款或自动外呼；主动联系由运营执行。

新增 `MatchLead` 表及增量迁移 `20260914160000_match_leads`，本地已应用。线上需在发布时应用迁移，本次未提交、推送或部署。

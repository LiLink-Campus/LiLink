# 学校邮箱 .cn 后缀支持

保留已配置的 `.edu.cn` 后缀，并支持移除 `.edu` 后的 `.cn` 别名，保留其他子域名前缀。例如 `muc.edu.cn → muc.cn`、`stu.blcu.edu.cn → stu.blcu.cn`。不扩展裸 `edu.cn` 或 `cn`。别名继承学校注册资格，不会启用被禁用的学校。同等匹配精度下，显式配置优先。

学校页展示、可注册学校接口和后端学校识别复用共享规则。规则不证明学校实际提供对应邮箱；仍需使用真实可收信的邮箱完成验证。

首页删除“提高配对率或许只需算法的让步……”段落，保留上方“在覆盖广度与心灵深度之间，我们选择后者。”。

验证：API 两组相关测试 14 项通过，共享测试 111 项通过，API/Web 类型检查通过；浏览器确认学校页别名及首页段落删除。未发送验证邮件，未完成真实邮箱注册，未部署。当前本机 4000 端口无 API 服务，后端运行服务需加载新代码后生效。

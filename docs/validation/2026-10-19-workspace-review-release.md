# 工作区审阅与发布前验收（2026-10-19）

> 文档归属：[验收记录](README.md)。当前契约见[账户参考](../reference/account.md)、[匹配参考](../reference/matching.md)，设计见[教育身份决策](../decisions/2026-10-19-education-verification.md)。

## 范围与环境

审阅从 `0c5be65c84100f6044167b0e15d96e95caa58dea` 开始的全部未提交改动，包含普通邮箱注册、教育认证、学校管理、匹配优先级、身份展示及用户中心。独立子代理分别审阅认证与数据一致性、匹配与迁移、前端交互，再由另一子代理检查浏览器结果。本文记录提交前本机证据，不能替代提交后的精确 SHA CI 或生产切换回执。

本机 macOS arm64、Node 24.20.0、npm 11.19.0、Git 2.55.0、Docker 29.5.2、Playwright 1.60.0。固定核心运行于项目 Linux 容器，使用隔离 PostgreSQL 17、Mailpit 与合成账号；真实邮件只到测试 Mailpit。Chromium、桌面 WebKit、移动 WebKit 分别记录，不将模拟设备称为实体 iPhone 或安装版 Safari。内置浏览器人工检查桌面 1280×900 和移动 375×844，版本无法读取时明确标为不可用。

## 审阅修复

- 管理员修改登录邮箱也进入共享邮箱所有权锁，并同时检查登录邮箱与教育邮箱，避免跨字段抢占与并发重复。
- 学校目录资格写入使用事务内新鲜读取；目录变更使用独占锁，注册与教育认证使用共享锁。学校合并、删除的校验和受影响账号读取移入锁内，统一用户与问卷更新顺序，避免失效资格写入、遗漏快照失效和反向锁序。
- 匹配多层优先级改用精确 BigInt 权重，兼容分按百万分之一取整；修复超过 549 人时 Number 安全精度上限阻断撮合的问题。生产构建包含新增 vendored 权重模块，接口与持久化投影仍可 JSON 序列化。
- 教育认证和注销请求设置有界期限并取消卸载请求。写入回执不确定时先读回状态，成功持久化不重复扣额度或重复提交；读回失败提供显式确认，弹窗可以退出。
- 邀请与 VIP 页面直接访问、刷新时补入服务端账号身份，恢复头像、姓名、完整账号菜单及注销入口。后台登录不再用冗余导航抢占紧接着的用户页导航。
- 学校合并文字按钮使用适合文字的宽度；长邮箱域名允许断行，避免移动页面横向溢出。
- 修正旧教育资格开关、VIP 文案、已移除用户中心锚点等过时验收夹具；复用既有测试，不在实现后新增单元测试。

## 发布边界

本文覆盖提交前验收，后续执行顺序为提交、精确提交的生产镜像演练、正常推送与精确提交 CI、暂存 Web 构建、API 迁移与切换、Web 域名提升和生产只读核验。生产镜像演练复现命令为 `node scripts/release/local-rehearsal.mjs`，要求相关源码已提交，使用内部 Docker 网络及一次性数据库，不访问公网业务系统。

发布前已对加密生产备份完成隔离恢复，并对恢复克隆执行候选迁移：旧未注销账号获得 LEGACY 教育身份、注销账号无教育身份、教育邮箱唯一约束通过。克隆已销毁；保护目录与备份内容不进入工件或 Git。迁移会改变新账号教育身份语义，回滚须同时评估旧 API/Web 与注册入口，不能仅下滚数据库迁移。

生产部署、远端 CI 与最终提交号以任务最后的实际回执为准。此前两篇同日功能验收文档中的“尚未提交/远端未执行”描述属于各次历史时点，由本次后续回执更新效力，不改写旧运行结果。

## 远端 CI 暴露的搜索输入时序

提交 `619fd975d0638f229c414cb4d3e3e13f5069bcc2` 的 [CI 39162392757](https://github.com/LiLink-Campus/LiLink/actions/runs/39162392757) 中，Storybook 通过，核心浏览器为 239/240；唯一失败发生于学校编辑流程的桌面 WebKit：填写搜索词后提交，页面仍显示 14 张初始卡片，而非两所合成学校。API、数据库 E2E 与其他浏览器用例通过；Sentry 专项因前序门禁失败尚未执行，不能补记为通过。

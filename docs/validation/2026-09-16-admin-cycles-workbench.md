# 轮次中心：图表、预演与审计整合

后续页面调整见[轮次列表常驻与统一编辑](2026-09-16-admin-cycles-flat.md)，其中列表折叠、参与者明细和执行操作的展示已更新。

## 页面与数据行为

- 移除独立「运营统计」导航及页面内容，原 `/admin/analytics` 地址跳转到 `/admin/cycles`。概览快捷入口改为轮次管理。
- 轮次列表默认收起，当前轮次显示报名截止与揭晓时间。「轮次设置」抽屉保留编辑、复制草稿及导出操作。
- 「参与者与完成度」统一展示问卷完成度、本轮学校与性别分布、最近 8 轮男女报名趋势；参与者明细按需展开。
- 当前轮次图表统计正常、未注销、已报名且已选择意图的账号，包含测试账号；草稿问卷计为未提交，其性别计为未知。趋势图采用相同账号与报名口径，女生占比以已知男女人数为基数。页面标注范围。
- 正式匹配组数与待联系组数只在概况展示；匹配结果区保留结果列表及必要的分页数量，去掉重复指标卡。
- 匹配结果统一为「预演 / 最终」两个视图。预演展示后端生成时间，精确到秒、北京时间；重新预演更新时间，切换轮次清空旧预演。正式执行与强制执行仍需现有确认。
- 预演列表是当前页面的临时结果，刷新后需重新生成；审计保留每次预演的时间、操作者及数量摘要，不保存完整预演配对历史。
- 删除轮次内运行记录及独立日志接口、无调用的分页日志辅助方法。预演新增 `cycle.previewed` 审计，正式生成/揭晓沿用既有审计记录。「查看本轮审计」带轮次筛选，搜索与分页都保留此范围。

未改变匹配算法、正式执行策略及揭晓规则，未接入 PostHog。没有数据库结构变更。

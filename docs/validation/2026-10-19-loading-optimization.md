# 首屏调度优化与独立审阅验收（2026-10-19）

> 文档归属：[验收记录](README.md)。

本记录对应从 `3fe6aa3650a593330ac5bd973bf71cc71150edd7` 开始的四项 Web 优化。保留公开 ISR、Data Cache、失效与追踪边界；API、共享协议、依赖锁和数据库迁移不变。当前契约见[公开数据缓存](../reference/public-data-cache.md)和[静态资源](../guides/static-cdn.md)。部署结果以对应 Git 提交的 CI 与 Vercel 回执为准。

## 设计与审阅

- 一对一页文字随服务端 HTML 展示；图片预览与淡入只控制插画。
- 学校页五个首屏校徽使用独立图集，屏外图集按实际裁切框进入视口加载。
- 后台轮次在既有私有 SSR 中读取初始十条，水合复用该份数据。筛选、刷新或身份变更仍按原契约取数，不新增公共缓存。
- 导航按鼠标、键盘或触控意图预取；Replay 延迟至 load 后两秒与空闲，或首错时后台加载。

三路独立子代理分别审查渲染与图片、后台 SSR 与去重、Replay 与缓存。发现并修复一个 P2：异步错误钩子等待录屏分包，用户快速完整导航时核心错误丢失。现在同步继续错误上报，后台尽力保存录屏；不重发错误，不手工伪造录屏关联。初始化前操作和首错关联、快速离页录屏均不保证保留。修复后二次审阅无新增确定缺陷。

## 可复现行为验收

环境为 Node 24、锁定 npm 依赖、Docker 一次性 PostgreSQL/Mailpit、合成用户和隔离 Chromium/WebKit。禁止将运行器指向生产数据库。命令与固定集合定义见[浏览器 E2E](../guides/browser-e2e.md)。

```sh
npm run test:ci
node scripts/e2e/run.mjs --sentry-tracing --project=chromium
```

本机原优化固定集合：浏览器 261、Sentry 3、Storybook 221、API 单元 574、API 集成 203、Web 110、共享 88、工具链 25 项通过。针对审阅发现，在修复应用前增加真实 SDK 的卡住/失败录屏下载及 250 毫秒完整导航用例：修复前两例失败，修复后两例通过；连同原缓存、请求追踪和录屏用例共五项通过。远端精确提交 CI 单独提供完整终态，不以本机结果代替。

关键断言包括：图片不返回时文字与登记入口仍可见；禁用 JavaScript 时五个首屏标志可显示；真实滚动后全部 28 个标志完整；轮次初始 SSR 无水合重复列表请求，手动刷新仍取数；匿名页面不泄露私有列表；导航意图与真实到达一致；可选监控分包不阻塞核心错误。

本机工件根目录为 `artifacts/performance/loading-optimization-20261019/`，包含 `report.html`、原始逐次样本、源码冻结、重跑命令、IAB 桌面/移动截图、WebKit 截图、胶片和三路 review；`replay-navigation-review/` 保留修复前后的 SDK 及完整 Next 结果。本机工件被 Git 忽略，不能当作仓库交付文件或远端下载链接。

## 性能对照及边界

主样本为移动 390×844、DPR 3、下行 1.6 Mbps、上行 0.75 Mbps、CDP 延迟参数 150 毫秒、CPU 四倍降速，每项十对冷/暖访问；另保留桌面与公开/登录页面补充样本。两版主要计时都关闭监控 DSN，监控另用真实 SDK 编译验证。以下为本机生产模式冷访问中位数，不代表大陆用户或线上效果。

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 一对一页正文标题稳定可见 | 2.62 秒 | 0.79 秒 |
| 学校页 LCP | 2.56 秒 | 2.02 秒 |
| 后台轮次列表可见 | 2.56 秒 | 1.01 秒 |
| 学校页首屏图集传输 | 496,616 字节 | 94,267 字节 |

学校页标题与 FCP 约晚 104 毫秒，容差结论为 INCONCLUSIVE；后台暖访问私有响应传输由 7,704 增至 9,856 字节。原始不利结果保留。审阅后的核心错误钩子修复不覆盖旧监控探针结果，另存修复后证据；主要性能表描述审阅前的冻结候选，最终提交仍需精确 CI 与上线核验。

## 用量风险

18 个缓存与失效实现文件保持不变；相同首页投影指纹保持一致，完整本地缓存对象的原始 8 KiB 舍入代理为 22→22，不能换算为生产压缩后的 ISR Writes。发布后的首次缓存填充和业务变更后的正常再生成仍可能写入。

屏外图集和路由预取减少首屏竞争，但部分脚本文件数增加，停留后录屏仍会下载。浏览器请求数不等于 Vercel CDN 计费请求。轮次一次浏览器列表读取移至既有动态 SSR，避免水合再读；SSR 执行时间和私有 HTML/RSC 大小仍可能增加 Functions 成本，监控 tunnel 流量也仍在。

本轮生产 ISR、CDN、Functions 查询因 `payment_required` 无权取得聚合值；这不表示资源配额耗尽，也不能证明账单下降。未升级套餐或修改缓存参数。上线后的实际用量变化仍需有权限的账单/观测数据确认。

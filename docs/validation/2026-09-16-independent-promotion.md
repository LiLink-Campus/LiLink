# 常态邀请推广与商户活动拆分

## 行为

- 「增长推广 / 邀请推广」按时间查看分享、访问、注册来源及邀请人排行；不选择商户活动，无活动也正常工作。
- 新注册和分享、访问事件不再绑定活动。旧归属字段保留历史数据，旧活动查询接口保留兼容；新邀请看板不再使用它们。
- 「商家合作 / 商户活动」采用草稿、发布、结束流程，删除默认活动设置和注册链接 slug 输入。系统自动生成内部标识。
- 发布前必须有有效优惠券和启用的商家；事务锁串行化发布与发券，同一时间只能有一个 ACTIVE 活动。
- 问卷已提交且曾报名匹配的新老用户都可领取当前活动奖励；在完成条件时以及访问优惠券页时尝试发券。每人每场一次，无有效券不会标记已发放。
- 已发布活动固定优惠券配置；结束后停止新增发放，已有券按原有效期继续使用。下一场活动可再次领取，旧记录保留。
- 发放统计、优惠券明细、按商家和日期核销对账集中到活动详情。核销面值是名义面值，不等于结算金额。
- 商家页重点管理核销账号，新增商家使用抽屉，核销后展示内容降为高级设置。
- 删除后台卡片侧边彩色竖线 / inset 侧边阴影，并将视觉偏好写入 `apps/web/AGENTS.md`。商家筛选下方只保留标签栏分隔线。

# 2026-09-16 后台视觉重构

按用户要求，先使用内置 image_gen 生图工具生成设计稿，再实施前端。范围为 `/admin` 下 12 个页面及管理员登录页；没有接入 PostHog，也没有修改业务接口、权限或数据库。

## 设计与实现

- 暖灰底、白色工作区、酒红主色，统一侧栏图标、页面宽度、标题、筛选、按钮、表格和空状态。
- 概览保留真实业务指标、当前轮次、待处理事项和快捷入口；低频设置折叠。
- 用户页改为表格和筛选栏。手机上逐条显示完整用户信息；详情在侧边抽屉打开，支持关闭按钮、Escape 和焦点返回。
- 学校、问卷改为连续列表；手机上题干与学校名可以换行，编辑区域适应屏宽。
- 轮次、商家、活动券包、举报、推广数据复用统一样式。审计元数据按需展开。运营统计采用独立图表颜色区分男女数据。
- 人工匹配登记统一为列表、计数和联系状态操作，包含加载、空数据及失败状态。

设计图只用作视觉参考，示意数字、虚构用户和未有的操作不进入真实业务页面。后台主题限制在管理布局中，不改变公开网站主题。

## 本地验证

- `npm run typecheck:web`、`npm run typecheck:storybook:web` 通过。
- 本次修改的 TypeScript/TSX ESLint、10 个 CSS 文件语法检查、`git diff --check` 通过。
- `npm run test:storybook:web -- --run apps/web/src/stories/admin-pages.stories.tsx`：29 个用例通过。覆盖后台各页、空数据/失败、用户抽屉开关和编辑、学校编辑、商家账号、券包展开、推广标签及人工登记状态往返切换。
- 真实本地服务的 12 页在 1440px 和 390px 检查，无页面脚本错误和整页横向溢出。
- 390、560、561、900、901、1440px 验证概览、设置展开、响应式导航、用户抽屉打开/编辑/关闭/Escape/焦点恢复和搜索空结果。
- Storybook 的合成数据覆盖有轮次、有统计、有举报、有商家和券包的展开状态；真实数据库没有为了展示而写入假数据。
